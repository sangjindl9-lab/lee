# 테스트 결과

- 실행: `npm test` (Node.js 22, `node:test`, 메모리 DB + 임시 파일 저장소 + 내장 테스트 결제 사업자)
- 결과: **52개 중 52개 통과** (2026-11-18 기준)
- 범위: 서비스 계층 직접 호출과 실제 HTTP 요청(쿠키·CSRF 포함)을 함께 사용합니다. 결제는 테스트 사업자의 서명된 웹훅 → 서버의 사업자 조회 경로를 그대로 탑니다.
- 한계: 실제 결제 사업자 대상 테스트는 없습니다. 브라우저 자동화 테스트는 저장소에 포함하지 않았고, 주요 화면의 데스크톱·모바일 렌더링과 파일 업로드 폼은 수동으로 확인했습니다.
