# 이음마켓 EUM MARKET

AI를 활용하거나 직접 만든 소프트웨어를 판매하고, 맞춤 개발을 의뢰하고, 소스코드와 지식재산권을 거래하는 플랫폼입니다.
회원가입부터 상품·납품 파일 등록, 주문, 결제 확인, 납품물 전달, 검수, 분쟁·환불, 판매자 정산까지 실제 데이터로 이어집니다.

> **현재 상태** — 결제는 내장 테스트 사업자(`sandbox`)로 동작합니다. 실제 돈은 이동하지 않고 결제대금 보호도 없으며, 화면에도 그렇게 표시됩니다.
> 실결제·대금 보호·자동 지급은 결제 사업자와의 계약과 검증이 끝나야 켤 수 있습니다. 자세한 내용은 [docs/05](docs/05-연동여부-미구현-출시전검토.md)를 보세요.

## 빠른 실행

```bash
npm install
cp .env.example .env        # 개발에서는 비워 둬도 됩니다(비밀값은 data/에 자동 생성)
npm run seed                # 선택: 예시 계정·상품·주문 생성
REQUIRE_ADMIN_MFA=0 npm start
# http://localhost:3000
```

예시 계정(비밀번호 `eum-demo-1234`): `admin@eum.test`(최고관리자), `seller@eum.test`, `buyer@eum.test`

```bash
npm test                    # 52개 테스트
```

## 구성

- Node.js 22 · Express · SQLite(better-sqlite3) · 서버 렌더링(별도 빌드 단계 없음)
- `src/migrations/` DB 스키마, `src/services/` 거래 로직, `src/providers/` 결제 사업자 계층, `src/routes/` 화면, `test/` 테스트
